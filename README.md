## About

This repository is a running log of my DSA practice. Each problem has its own folder, so a solution is easy to find and the history shows how my problem-solving has progressed over time.

## Repository Structure

Every problem lives in a folder named `<problem number> <problem title>`:

```
LeetCode_Solutions/
├── 1 Two Sum/
├── 11 Container With Most Water/
├── 15 3Sum/
├── 104 Maximum Depth of Binary Tree/
├── 1143 Longest Common Subsequence/
└── ...
```

Each folder contains the solution file for that problem.

## Topics Covered

The problems span the core areas of interview-style DSA practice:

- **Arrays & Strings**: two pointers, sliding window, prefix sums
- **Hashing**: frequency counting, lookups
- **Linked Lists**: cycle detection, reordering, intersections
- **Trees**: traversals (pre/in/post/level order), BST, path sums, lowest common ancestor
- **Graphs**: DFS/BFS, cloning, connected regions
- **Dynamic Programming**: subsequences, grid DP, 1D/2D DP
- **Stack & Parentheses problems**
- **Math & Bit Manipulation**
- **Sorting, Intervals & Greedy**
- **Backtracking & Recursion**

## How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/VickZeus/LeetCode_Solutions.git
   cd LeetCode_Solutions
   ```
2. Open the folder of the problem you're interested in, for example `1 Two Sum`.
3. Read the solution, or copy it into LeetCode's editor to test it.

To find a problem quickly, search the folder names:

```bash
ls | grep -i "binary tree"
```
